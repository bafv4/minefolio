# Changelog

## v1.4.0 (準備中)

### 設定プリセット

- 編集タブ（`/me/keybindings` `/me/devices` `/me/items` `/me/search-craft`）の上部にプリセット切替ドロップダウンを追加。
- 編集内容を保存すると、アクティブプリセットのスナップショットも自動更新するように。
- プリセット切替・作成時の不整合を修正（フィールド欠落・部分復元など）。
- カスタムキー定義・カスタムアクションをプリセット対象に追加。
- プロフィール画面（`/player/:slug`）でプリセット切替時にローディングオーバーレイを表示。

### ガイド

- ガイド管理ページを `/me/guides/*` から `/my-guides/*` に移動。ヘッダーのユーザードロップダウンに「マイガイド」リンクを追加。
- 編集ページのURLを `/my-guides/:guideSlug/edit` に変更。
- 編集ページでブラウザの綴りバリデーションを無効化。
- 編集ページのスティッキーヘッダーとツールバーを背景透明化。
- 公開ガイド表示ページ（`/guides/:authorSlug/:guideSlug`）でオーナー本人がアクセスした場合に編集ボタンを表示。
- ガイド内のリマップキーボードに「チャット」操作を表示するように。
