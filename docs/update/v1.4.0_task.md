# v1.4.0 変更予定箇所一覧
1. 編集時（`/me/*`）の設定プリセットの選択を改善
   * 現在編集中のプリセット=保存時に内容が反映されるプリセットにする
   * 「キー配置」「デバイス」「アイテム配置」「サーチクラフト」の上部に表示されている「現在編集中のプリセット」表示について
     * ドロップダウンで編集先・保存先を指定できるようにする
     * 現在編集中のプリセットに変更がある場合はドロップダウンを非活性とする
     * ドロップダウンの選択内容は各タブで同期するようにする。
     * スタイル改善
2. ガイド関連
   1. 自分の作成したガイドの一覧ページ（`/me/guides/`）を`/me`ルートから切り離し、`/my-guides`ルートにする。
      * ページ自体も`/me`から切り離す。
      * ユーザー情報のドロップダウン（ヘッダーのユーザーアイコンクリック時に表示されるドロワー）の「設定」の次の項目に、`/my-guides`に遷移するリンクを追加する。
   2. 編集ページ（現`/me/guides/:guideSlug/edit`）関連
      * 編集ページも`/my-guides/:guideSlug/edit`ルートとする。
      * 編集ページでは綴りのバリデーションを無効化する。
      * 編集ページ上部のツールバーの周り（公開設定や保存ボタンのあたり）の背景色を透明にする。
   3. ガイド表示ページ（`/guides/:authorSlug/:guideSlug`）
      * ログインユーザーがそのガイドのオーナーの場合、ページ上部に編集ページ（`/my-guides/:guideSlug/edit`）に遷移するボタンを表示するようにする。
      * ガイドに表示するリマップのキーボードに、「チャット」の操作を表示するようにする。
3. お気に入り機能の大規模改善
   * `favorites`テーブルを作成し、ログインユーザーのお気に入り登録はデバイス依存ではないようにする。
   * 既存のローカルストレージのお気に入り情報は、ログイン時に自動でテーブルに追加登録（重複は無視）する。追加登録時にローカルストレージの情報は削除する。
   * お気に入り一覧を取得するAPIを新設する
     * ログイン時・ページ読み込み時（ログインセッション継続中の場合）に実行して、リストをセッションストレージに保持する
     * CRUD用のAPIも追加する。
   * お気に入り表示時：
     * ログインユーザー：セッションストレージ・ローカルストレージから参照
     * 一般ユーザー：ローカルストレージから参照
     * Cookieの使用許可をしていない場合はローカルストレージを参照しない。（引き続き）
4. ユーザーロールに関する仕様変更
   * 各一覧表示・ペース表示・動画、ライブ表示で「視聴者」ロールのユーザーをデフォルトで表示しないようにする。
   * 上記お気に入り機能の改善に伴い、自分の設定を登録しないユーザーの新規登録が増加することを想定（念のため）した対応
   * `/browse`のみ、視聴者ロールの人を表示できるようにする。（絞り込みで「視聴者」ロールを選択することによって）
   * `/keybindings`の一覧には「視聴者」ロールの人は表示しない。`/keybindings/stats`の「登録走者数」の集計には視聴者ロールの人数を含めない。
   * ホーム画面（`/`）の「公開プロフィール総数」「アクティブプロフィール数（7日）」に視聴者ロールの人数を含めない。
5. 開発者用ページ
   * 開発者用の情報を掲載するページ（`/developers`）を新設する。
   * フッターの「Donate Me!」の隣に「開発者用」リンクを追加する。
   * フッターにある「CSVエクスポート」ボタンはこのページに移動する。（フッターからは削除）
   * ページ内にAPIドキュメントを作成する。（`markdown-it`を使用して[APIルート仕様書](../api.md)を公開用に少し書きなおしたものを表示?）
   * [Changelog](../changelog/changelog.md)も↑と同じようにできたらいいなあ。
