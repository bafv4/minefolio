# プライバシーポリシー

Minefolio（以下「本サイト」）は、ばふ（bfmkn）（以下「運営者」）が個人で運営する、Minecraft RTA走者向けのポートフォリオプラットフォームです。本ポリシーは、本サイトがユーザーの情報をどのように取得・利用・管理するかを定めるものです。

## 1. 取得する情報

### (1) Discord アカウント連携により取得する情報

本サイトへのログインには Discord アカウントを使用します。連携時に以下の情報を取得します。

- Discord ID・ユーザー名
- アバター画像
- メールアドレス

> メールアドレスは、ログイン（アカウントの識別・不正利用防止）のためにのみ Discord から取得・保存しています。本サイトの画面に表示されることはなく、第三者への提供や外部サービスへの送信にも使用しません（本サイトからのメール配信も行っていません）。

### (2) ユーザーが任意に登録する情報

- Minecraft ID（MCID）・UUID、スキン
- 表示名、自己紹介、所在地、代名詞などのプロフィール情報
- 使用デバイス・キー配置・マウス設定などのプレイ環境情報
- Speedrun.com / Twitch / YouTube など外部サービスのユーザー名・リンク

> MCID の登録は自己申告制であり、Microsoft アカウント認証等による本人確認は行っていません。

### (3) 投稿コンテンツ

- ガイド記事および添付画像
- リアクション、いいね、お気に入り
- フィードバックフォームの送信内容

### (4) 自動的に取得する情報

- ログインセッションの管理に伴う IP アドレス・ブラウザ情報（User-Agent）。ログインセッションの記録として保存されます（セッションの有効期間は最長 7 日間。期限切れのセッション記録は毎日の定期処理で削除されます）
- Cookie（後述）
- ページの閲覧状況（アクセス解析。個人を特定しない集計値として利用します）

## 2. 利用目的

取得した情報は、以下の目的で利用します。

1. 本サイトの提供・運営（ログイン認証、プロフィール・記録・設定の表示）
2. アカウントの識別、不正利用・なりすましの防止
3. 外部サービス（Speedrun.com 等）からの記録・統計・動画情報の取得と表示
4. フィードバックへの対応（内容の確認等のため、運営者から Discord を通じてご連絡する場合があります）
5. 利用状況の把握と機能改善（集計値によるアクセス解析）

## 3. Cookie 等について

本サイトは以下の目的で Cookie およびブラウザのローカルストレージを使用します。

- **ログインセッションの維持**（必須）
- **言語設定の保存**（Cookie）
- **テーマ設定の保存**（ローカルストレージ。サーバーへは送信されません）
- **ログインしていない状態でのお気に入りの保存**（ローカルストレージ。お気に入りしたプレイヤーの一覧はお使いのブラウザ内に保存されます）
- **その他の利便性のための保存**（ローカルストレージ等。お知らせの既読状態、Cookie 同意バナーでの選択、プレイグラウンドの編集内容の下書き、お気に入り一覧の一時キャッシュ。いずれもお使いのブラウザ内にのみ保存されます）
- **アクセス解析**（Vercel Web Analytics。個人を特定する Cookie は使用しません。送信先・送信される情報の詳細は「5.」をご覧ください）

## 4. 外部サービスへの情報送信・処理の委託

本サイトはサービスの提供にあたり、以下の外部サービスを利用しています。これに伴い、それぞれのサービスへ情報が送信・保存されます（サーバーからの送信のほか、ページの表示に伴いユーザーのブラウザから直接送信されるものを含みます）。

| サービス | 提供者 | 用途 | 送信・保存される主な情報 |
|---|---|---|---|
| Vercel | Vercel Inc. | ホスティング・アクセス解析・画像等の保存 | アクセス情報全般、アップロードされた画像・スキン |
| Turso | Turso（旧 ChiselStrike） | データベース | 本サイトに登録された情報全般 |
| Discord | Discord Inc. | ログイン認証、アバター画像の配信 | OAuth 認証情報。アバター画像は Discord の CDN から閲覧者のブラウザへ直接配信されます |
| Mojang API | Mojang / Microsoft | MCID・UUID の確認、スキンの取得 | MCID・UUID |
| Speedrun.com / MCSR Ranked / PaceMan | 各運営者 | 公開されている記録・統計・ペース情報の取得 | 登録された各サービスのユーザー名・UUID（取得のみ） |
| Twitch / YouTube | Twitch Interactive / Google | 連携チャンネルの動画・配信情報の取得、動画の埋め込み再生 | 登録されたチャンネル情報。埋め込みプレイヤーの表示・再生時は、閲覧者のブラウザから各サービスへ直接通信が発生します |
| MCSRer Hotkeys（旧サービス） | 運営者 | 旧サービスからの設定インポート（ユーザーが実行した場合のみ） | MCID |
| Resend | Resend Inc. | フィードバックの運営者への通知メール送信 | フィードバックの内容と送信者情報（Discord ID・MCID・表示名） |
| GitHub | GitHub Inc. | フィードバックの公開 Issue 化（ユーザーが同意した場合のみ） | フィードバックの件名・本文（送信者の個人情報は含めません） |
| Anthropic | Anthropic PBC | ガイド記事・自己紹介文の自動翻訳 | 翻訳対象のテキスト |

> 本サイトは **YouTube API サービスを使用しています**。これに伴い、[Google プライバシーポリシー](https://www.google.com/policies/privacy)が適用されます。
>
> Web フォントは本サイト自身のサーバーから配信しており（セルフホスト）、フォント取得のために外部サービスへ通信することはありません。

## 5. 利用者の端末から外部へ送信される情報（外部送信規律に基づく公表）

本サイトでは、サービスの利便性向上や利用状況の把握のために、外部の事業者が提供する仕組みを利用しています。これに伴い、本サイトを閲覧するみなさまのパソコンやスマートフォン（端末）から、以下の外部事業者へ情報が送信されることがあります。電気通信事業法の「外部送信規律」に基づき、送信される情報の内容・送信先・利用目的を公表します。

### (1) アクセス解析（Vercel Web Analytics）

本サイトのすべてのページで、利用状況を計測するために以下の情報が送信されます。

| 項目 | 内容 |
|---|---|
| 送信先 | Vercel Inc.（バーセル） |
| 送信される情報 | 閲覧したページのURL、リンク元のページ（リファラ）、ブラウザ・OS・画面サイズの種類、おおまかな地域情報 |
| 利用目的 | 本サイトの利用状況の把握と機能改善（個人を特定しない集計のみに使用します） |

この計測は Cookie（クッキー）を使用せず、送信された情報から個人が特定されることはありません。

### (2) YouTube 埋め込みプレーヤー（Google LLC）

ガイド記事・プロフィールページ・動画一覧などで YouTube の動画を表示・再生すると、YouTube を運営する Google へ情報が送信されます。

| 項目 | 内容 |
|---|---|
| 送信先 | Google LLC（グーグル） |
| 送信される情報 | 端末に保存された Google の Cookie 等の識別子、閲覧しているページのURL、動画の再生・視聴に関する情報 |
| 利用目的 | 動画の再生機能の提供、視聴履歴の記録、Google にログインしている場合のアカウントとの関連付けなど。詳しくは [Google プライバシーポリシー](https://policies.google.com/privacy) をご覧ください |

- 本サイトが生成する埋め込みは、プライバシー強化モード（youtube-nocookie.com。動画を再生するまで端末に Cookie を保存しない仕組み）を使用しています
- 動画一覧・ホームの動画カードは、サムネイルをクリックするまでプレーヤーを読み込みません
- ガイド記事に埋め込まれた動画は、記事を書いた利用者が選んだものです

### (3) Twitch 埋め込みプレーヤー（Twitch Interactive, Inc.）

動画一覧・ホームで Twitch の配信アーカイブを再生すると、Twitch へ情報が送信されます。

| 項目 | 内容 |
|---|---|
| 送信先 | Twitch Interactive, Inc.（ツイッチ） |
| 送信される情報 | 端末に保存された Twitch の Cookie 等の識別子、閲覧しているページのドメイン名、動画の再生・視聴に関する情報 |
| 利用目的 | 動画の再生機能の提供、視聴履歴の記録など。詳しくは [Twitch プライバシーポリシー](https://www.twitch.tv/p/legal/privacy-notice/) をご覧ください |

- サムネイルをクリックするまでプレーヤーを読み込みません（クリックして初めて送信が発生します）

### (4) 上記にあたらないもの

- **ログイン用の Cookie**: 本サイト自身が発行し、本サイトだけが使うものです。外部への送信はありません
- **言語設定・テーマ設定など**: 本サイト内でのみ使用します（「3. Cookie 等について」参照）
- **プレイヤーのスキン画像・アイテム画像・Web フォント**: 本サイト自身のサーバーから配信しており、外部の事業者へ端末の情報を送信させるものではありません

## 6. 第三者提供

運営者は、次の場合を除き、取得した個人情報を第三者に提供しません。

1. 本人の同意がある場合
2. 法令に基づく場合
3. 「4.」の外部サービスへの委託・送信（利用目的の達成に必要な範囲に限ります）

## 7. 公開される情報

- プロフィール（表示名・MCID・プレイ環境・記録など）は、ユーザー自身の公開設定（公開 / 限定公開 / 非公開）に従って公開されます
- 公開したガイド記事は誰でも閲覧できます
- フィードバックの Issue 化に同意した場合、件名と本文が公開リポジトリに掲載されます。送信者の個人情報（Discord ID・MCID 等）は Issue に含まれません

インターネット上に公開された情報は第三者に保存・転載される可能性があります。公開範囲はユーザー自身の責任で設定してください。

## 8. 安全管理

運営者は、取得した情報への不正アクセス・漏えい・滅失を防ぐため、アクセス制御・通信の暗号化など合理的な安全管理措置を講じます。

## 9. ユーザーによる情報の管理

- **公開範囲の変更**: プロフィールの公開設定はいつでも変更できます
- **アカウントの削除**: 設定ページからアカウントを削除できます。削除に伴い、アカウント・登録されたデータ・アップロードされた画像等のファイル・翻訳キャッシュは削除されます。MCID に紐づくペース履歴のみ、アカウントとの関連付けを解除した形で保持されます
- **MCID の不当な登録の申告**: 自分の MCID が本人の許可なく他のユーザーのアカウントに登録されている疑いがある場合は、[フィードバックフォーム](/feedback)からご連絡ください。運営者が確認のうえ、当該登録の削除等の措置を行います

その他、個人情報の開示・訂正・削除のご要望は、下記のお問い合わせ先までご連絡ください。

## 10. 未成年者の利用

未成年のユーザーは、保護者の同意を得たうえで本サイトを利用してください。

## 11. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更されることがあります。重要な変更を行う場合は、本サイト上で告知します。

## 12. お問い合わせ

本ポリシーに関するお問い合わせは、本サイトの[フィードバックフォーム](/feedback)からお願いします。
