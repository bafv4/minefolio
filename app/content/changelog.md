# Changelog

## v1.4.0 (準備中)

### 設定プリセット

- 編集タブ（`/me/keybindings` `/me/devices` `/me/items` `/me/search-craft`）の上部にプリセット切替ドロップダウンを追加。
- 編集内容を保存すると、アクティブプリセットのスナップショットも自動更新するように。
- プリセット切替・作成時の不整合を修正（フィールド欠落・部分復元など）。
- カスタムキー定義・カスタムアクションをプリセット対象に追加。
- プロフィール画面（`/player/:slug`）でプリセット切替時にローディングオーバーレイを表示。

### ガイド

- ガイド管理ページを `/me/guides/*` から `/my-guides/*` に移動。ヘッダーのユーザードロップダウンに「ガイド」リンクを追加。
- 編集ページのURLを `/my-guides/:guideSlug/edit` に変更。
- 編集ページでブラウザの綴りバリデーションを無効化。
- 編集ページのスティッキーヘッダーとツールバーを背景透明化。
- 公開ガイド表示ページ（`/guides/:authorSlug/:guideSlug`）でオーナー本人がアクセスした場合に編集ボタンを表示。
- ガイド内のリマップキーボードに「チャット」操作を表示するように。

### お気に入り機能の刷新

- お気に入りの保存先を Cookie から DB（ログイン中）／localStorage（未ログイン）に変更。デバイス間でお気に入りが共有されるように。
- `favorites` テーブルを slug ベースに刷新。
- `/api/favorites` を GET/POST/PUT 対応に書き換え。`POST /api/users/by-slugs` を新設。
- 旧 `minefolio_favorites` Cookie は API 応答で自動削除。
- ログイン直後に localStorage の旧お気に入りを DB に一括同期。
- ログイン中はクライアント側で sessionStorage にキャッシュし、ページ間の状態を保持。

### ユーザーロール仕様変更

- 視聴者ロール（`role = "viewer"`）のユーザーを各一覧表示・ペース表示・動画/ライブ表示・ホーム画面のカウントからデフォルトで除外。
- `/browse` ではロールフィルタで「視聴者」を選択することで明示的に表示可能。
- `/keybindings` 一覧および `/keybindings/stats` の「登録走者数」「キーバインド設定者数」「マウス設定者数」集計から視聴者を除外。
- ホーム画面（`/`）の「公開プロフィール総数」「アクティブプロフィール数（7日）」から視聴者を除外。
- PaceMan キャッシュ更新・ランキング更新・YouTubeチャンネル取得の Cron からも視聴者を除外。

### Developers ページ

- `/developers` ページを新設し、API ドキュメント・更新履歴・データエクスポートを掲載。
- フッターに「Developers」リンクを追加（「Donate Me!」の隣）。
- フッターから「CSVエクスポート」ボタンを削除し、`/developers` ページに移動。

### その他のUI改善

- プロフィール画面（`/player/:slug`）モバイル表示のタブ選択ドロワーのアイコンをハンバーガーから `↓↓` に変更。
- スキンの全身表示でドラッグによる回転・右ドラッグによる移動・ホイール/ピンチによる拡大縮小を可能に。表示をリセットするボタンも追加。
- ヘッダー・モバイルナビから「比較」リンクを削除（ページ自体は引き続き `/compare` でアクセス可能）。
