## v1.8.0（2026/07/18）

### キーリマップ種別

- キーリマップに種別（Trigger / Chat / All / 未設定）を追加しました。
  - **Trigger**: ゲーム入力用のリマップ。
  - **Chat**: チャット・サーチクラフトの文字入力用のリマップ。
  - **All / 未設定**: すべての用途で有効です。既存のリマップは「未設定」として扱われます。
- 同じキーでも種別が異なれば複数のリマップを登録できるようになりました（All は同じキーの他の種別と併用できません）。
- プロフィールのキーボードビューと、キー配置一覧のビジュアルカードビューに Trigger / Chat の表示切替を追加しました（カードビューの切替は全カード共通です）。
- ガイドのリマップ埋め込みには、Trigger 以外（Chat / All / 未設定）のリマップが表示されるようになりました。
- サーチクラフトの入力キー計算・タイピングテストには Chat / All / 未設定のリマップのみが使われるようになりました。
- リマップ一覧に種別バッジを表示するようにしました（未設定はバッジなし）。
- 開発者向けCSVエクスポートのリマップに「Type」列を追加しました。

### サーチクラフトテンプレート・Playground

- テンプレートや Playground の内容を自分の設定に反映したときに挿入されるリマップは「Chat」として登録されます（キーボードビューの Trigger 表示には表示されません）。
- 反映時、既存の Trigger / All のリマップは削除されません。ただし、反映するリマップと同じキーの All のリマップは Trigger に変換されます。

### その他

- 一部の情報表示色（info系）がテーマに反映されない問題を修正しました。
- プリセット表示で、文字出力のリマップが正しく表示されない問題を修正しました。

## v1.7.0（2026/07/16）

### ガイド
- ガイドのURL（スラッグ）を編集できるようにしました。編集画面の「設定」モーダルの「URL」欄から変更できます。半角英小文字・数字・「-」「_」が使えます。
- URLを変更して保存・仮保存すると、以前のURLは無効になります。
- ガイドのサーチクラフト埋め込みで、タイミングが「OW」「Bastion→Fort」「Blinded」のクラフトが表示されない問題を修正しました。

### サーチクラフト
- 「Shiftを押しながらクラフトする」オプションを追加しました。編集画面（設定・テンプレート・Playground）の各行で設定でき、有効にすると表示行の入力キーに「⇧ Shift」バッジが付きます。
- 入力キーの表示で、同じ文字を複数のリマップが出力できる場合に、修飾キーなしで押せるキーを優先して表示するようにしました。
  - 例: `E→h` と `⇧S→h` がある場合、`h` の入力キーは `⇧+S` ではなく `E` になります。
  - ただし、「Shiftを押しながらクラフトする」オプションが有効の場合は、シフトキー付きの `⇧+S` が使われます。
- プロフィールの設定画面の「追加」ボタンを移動しました。
- 設定のサーチクラフトで「プリセットからコピー」を実行するとエラー画面になる問題を修正しました。

### Playground・テンプレートエディタ
- バーチャルキーボードを一番上に表示するようにしました。
- タイピングテストを、バーチャルキーボード右上のボタンから開くモーダルに変更しました。

### その他
- SNS共有時のOGPを見直しました。プレイヤーページ・個別ガイド記事以外のページは、アプリアイコンのみのシンプルな画像を表示するようにしました。
- トップページ専用のOGP（横長バナー）を新設しました。

## v1.4.0（2026/05/02）

### 設定プリセット

- 各設定タブ（キー配置・デバイス・アイテム配置・サーチクラフト）の上部に、編集中のプリセットを切り替えるドロップダウンを追加しました。
- 設定を保存すると、その内容が編集中のプリセットにも自動で反映されるようになりました。
- プリセットを切り替えても設定の一部が引き継がれない不具合を修正しました。
- カスタムキーやカスタムアクションもプリセットの保存対象に含まれるようになりました。
- 公開プロフィール画面でプリセットを切り替えるとき、読み込み中のオーバーレイが表示されるようになりました。

### ガイド

- 自分のガイド管理ページが `/my-guides` に独立しました。ヘッダーのユーザーメニューから直接アクセスできます。
- 編集ページの URL を分かりやすい形式（`/my-guides/:guideSlug/edit`）に変更しました。
- 編集ページではブラウザの綴りチェック（赤い波線）が表示されないようにしました。
- 編集ページのツールバー周辺の背景を透明にし、文章に集中しやすくしました。
- 公開済みのガイドを自分で開いたとき、ページ上部に編集ボタンが表示されるようになりました。
- ガイドに表示するリマップ用キーボードに「チャット」操作も表示されるようになりました。

### お気に入り

- ログイン中のお気に入りがブラウザやデバイスを跨いで同期されるようになりました。
- ログイン直後に、それまでブラウザに保存していたお気に入りを自動でアカウントに引き継ぎます。
- 未ログインの場合は引き続きブラウザに保存されます（Cookie の同意が必要）。

### 視聴者ロール

- 視聴者ロールのアカウントは、各一覧・ペース表示・ライブ・ホーム画面のカウントなどからデフォルトで除外されるようになりました。
- `/browse` のロールフィルタで「視聴者」を選択した場合のみ表示されます。
- `/keybindings` 一覧やキーバインド統計、ホーム画面の公開プロフィール数なども、視聴者を含まないカウントに揃えました。

### Developers ページ

- `/developers` ページを新設しました。API ドキュメント・更新履歴・データエクスポートをここから利用できます。
- フッターに「Developers」リンクを追加しました（旧フッターの「CSVエクスポート」はこのページに移動しています）。
- データエクスポートでは、設定登録済みの全ユーザーまたは選んだユーザーだけを対象に CSV をダウンロードできます。

### その他

- プロフィール画面のスキン全身表示が、ドラッグで回転・右ドラッグで移動・ホイール/ピンチで拡大縮小できる立体ビューになりました。表示をリセットするボタンも用意しています。
- モバイル表示時のタブ切り替えメニューのアイコンを変更しました。
- ヘッダーから「比較」リンクを削除しました（`/compare` ページ自体は引き続き利用できます）。
