> このMarkdownは公開用ガイドのプロトタイプ原稿です。詳細は [`README.md`](./README.md) を参照してください。

## はじめに — Minefolioとは

Minefolioでできることを一言でまとめると、「**MinecraftRTAに関する自分の情報を1か所にまとめて公開する**」ことです。

- キーバインド・キーリマップ・マウス設定・コントローラー設定を記録し、仮想キーボード上で見やすく表示
- RTA記録（Speedrun.com / MCSR Ranked / 自己申告のカスタム記録）をまとめて表示
- 攻略ガイドやサーチクラフト（クラフト検索文字列）の一覧を執筆・公開
- 他のランナーのプロフィールを検索したり、2人のキー配置を並べて比較したりできる

登録・利用は無料で、Discordアカウントでログインするだけで始められます。

## アカウントを作る

### Discordでログイン

トップページ右上（モバイルではメニュー内）の「ログイン」から `/login` ページへ進み、「**Discordでログイン**」ボタンを押します。Discordの認証画面に遷移し、許可すると自動的にMinefolioへ戻ってきます。

![ログイン画面。「Discordでログイン」ボタンが中央に表示されている](images/usage-01-login.png)
*撮影メモ: `/login` ページ全体。*

### Minecraft ID（MCID）を登録する

初回ログイン時はオンボーディング画面（`/onboarding`）に案内されます。

1. 「Minecraft ID (MCID)」欄に自分のMCIDを入力し、「**検証して続行**」を押します。Mojang APIで実在確認が行われ、成功するとUUIDとスキンが自動取得されます。
2. MCIDをまだ決めていない、あるいは後で登録したい場合は「**MCIDなしで登録**」から進めます。MCIDは後からいつでも設定ページで追加できます。
3. 検証に成功すると確認画面に移り、アバターとMCIDのプレビューが表示されます。内容を確認して「**セットアップを完了**」を押せば登録完了です。

![MCID入力画面。入力欄の下に「検証して続行」ボタン、区切り線の下に「MCIDなしで登録」ボタンがある](images/usage-02-onboarding-mcid.png)
*撮影メモ: `/onboarding` の最初のステップ。両方のボタンが同一画面に写るように。*

![MCID検証成功後の確認画面。アバターとMCIDのプレビュー、「セットアップを完了」ボタン](images/usage-03-onboarding-confirm.png)
*撮影メモ: MCID検証に成功した直後の状態。*

登録が完了すると、自分のプロフィールページ（`/player/自分のslug`）へ移動します。

> 💡 以前に別アプリ（MCSRer Hotkeys等）でキー配置を管理していた場合は、後述の[「他アプリからの移行」](#他アプリからの移行インポート)でデータを引き継げます。

## プロフィールを整える

ヘッダーのユーザーメニュー（右上のアバター）から「**設定**」を選ぶか、直接 `/me/edit` にアクセスすると、プロフィール編集画面が開きます。ここが自分の情報を管理する起点になります。

編集画面のサイドバーには以下の項目が並びます。

| メニュー           | できること                                                       |
| ------------------ | ---------------------------------------------------------------- |
| プロフィール編集   | 表示名・自己紹介・スキン・ソーシャルリンク・動画欄・公開設定など |
| 記録               | RTA記録の登録                                                    |
| キー配置           | キーバインド・キーリマップの編集                                 |
| デバイス           | キーボード/マウス/コントローラー設定                             |
| アイテム配置       | ホットバー構成の記録                                             |
| サーチクラフト     | クラフト検索文字列の登録                                         |
| プリセット（補助） | 複数の設定セットの保存・切替                                     |
| インポート（補助） | 他アプリからのデータ移行                                         |

![プロフィール編集ページ全体。表示名・自己紹介・スキン・ソーシャルリンクのカードが並んでいる](images/usage-04-edit-overview.png)
*撮影メモ: `/me/edit` を上から見た全体像。*

### 基本情報

「プロフィール編集」では、表示名・自己紹介（Markdown対応）・所在地・代名詞・メインプラットフォーム（Java/Bedrock、PC/Switch等）・操作方法バッジなどを設定できます。カスタムスキンのアップロードにも対応しています。

### 動画欄

プロフィールに表示するYouTube動画を複数登録できます。それぞれにタイトルを付けられ、特に見てほしい1本を「**ピン留め**」すると、プロフィール上で大きく表示されます。ピン留めしていない動画は一覧表示になります。

![動画カード。2件の動画が登録され、うち1件にピンアイコンが付いている](images/usage-05-edit-videos.png)
*撮影メモ: 動画を2件以上登録し、1件をピン留めした状態の「動画」カード。*

### ソーシャルリンク・公開設定

Speedrun.com / YouTube / Twitch / Twitter（X）およびカスタムリンクを登録できます。また、プロフィールの公開範囲（公開/限定公開/非公開）もこの画面から設定します。

> ⚠️ 「危険な操作」欄からアカウント削除もできますが、プロフィール・記録・設定などすべてのデータが削除され元に戻せません。

## キー操作・デバイス設定を記録する

### キー配置（`/me/keybindings`）

自分が実際に使っているキーバインド（前進・後退・インベントリを開く等の操作に割り当てたキー）と、AutoHotkeyやKarabinerなどで行っているキーリマップを登録できます。画面上部には仮想キーボードが表示され、設定した内容がリアルタイムに反映されます。

キーリマップには**種別**を設定できます。

- **Trigger**: ゲーム内操作用のリマップ
- **Chat**: チャット入力・サーチクラフト用のリマップ
- **All**: 両方の用途で有効（同じキーに他の種別を重ねて登録することはできません）
- **未設定**: 種別を指定しない（Allと同じ扱いで、両方の用途に使われます）

同じキーでも「ゲーム内ではAキーだがチャット欄では元のキーのまま」といった使い分けを記録できるのが特徴です。

![キー配置編集画面。仮想キーボードとリマップ一覧。Trigger/Chatの種別セレクタが見える](images/usage-06-keybindings.png)
*撮影メモ: `/me/keybindings` で、Trigger/Chat種別を設定したリマップ行を含む状態。*

### デバイス（`/me/devices`）

キーボードのモデル・レイアウト、マウスのモデル・DPI・ゲーム内感度・Windows感度・cm/360・Raw Input・マウス加速の有無、コントローラー設定、視点感度・FOV・GUIスケールといったゲーム内設定をまとめて記録します。

![デバイス設定画面。マウスのDPI・感度・cm/360の入力欄](images/usage-07-devices.png)
*撮影メモ: `/me/devices` のマウス設定セクション。*

### アイテム配置（`/me/items`）

序盤・ネザー・エンド・要塞など、ゲーム進行フェーズごとのホットバー構成（どのスロットに何のアイテムを置くか）を視覚的に記録できます。

### サーチクラフト（`/me/search-craft`）

クラフト検索（かまど・作業台などの検索窓）で使う検索文字列と、それに対応する実際の入力キーを登録します。キーリマップと連動しており、Chat/All/未設定のリマップが自動的に反映された「実際に押すキー」が表示されます。

---

## 記録を管理する

`/me/records` では、カテゴリ別の自己ベストタイムや目標タイムを登録できます。Speedrun.comのユーザー名を連携している場合は、Speedrun.com上の自己ベストも自動的に取得・表示されます。特に見てほしい記録は動画・ガイドと同様に「ピン留め」して目立たせることができます。

---

## プリセットで複数の設定を使い分ける

`/me/presets` では、キーバインド・デバイス設定・キーリマップ・アイテム配置・サーチクラフトなど一式を「**プリセット**」として名前付きで保存できます。例えば「通常配信用」「大会用」のように複数のプリセットを作り、使う設定をワンクリックで切り替えられます。

- 現在編集中の内容が「アクティブなプリセット」として扱われます
- プリセット一覧から切替・複製・削除・名前や説明の編集ができます
- キー配置・デバイス・アイテム配置・サーチクラフトの各編集ページ上部からも、プリセットの切替ができます（未保存の変更がある間は切替できません）

![プリセット一覧。複数のプリセットが並び、1つに「アクティブ」バッジが付いている](images/usage-08-presets.png)
*撮影メモ: `/me/presets` で2件以上のプリセットが並んだ状態。*

## 他のランナーを探す

### 探す（`/browse`）

ヘッダーの「探す」から、登録されているランナーを一覧・検索できます。ログイン中はお気に入りのランナーが先頭に表示されます。

![ランナー一覧のカードグリッド](images/usage-09-browse.png)
*撮影メモ: `/browse` のカードグリッド表示。*

### お気に入り

各プロフィールページの「お気に入り」ボタンから、気になるランナーをお気に入り登録できます。登録したランナーは `/favorites` で一覧確認でき、未ログインでもブラウザ内に保存されます（ログインするとアカウントに同期されます）。

### 比較（`/compare`）

2人のランナーのキーバインド・キーリマップ・デバイス設定を並べて比較できる機能です。`/compare?player1=A&player2=B` のようにURLでプレイヤーを指定するか、画面上の検索フォームから選択します。設定が異なる項目はハイライト表示されます。

![2人のプレイヤーのキーバインドとデバイス設定を並べた比較画面](images/usage-10-compare.png)
*撮影メモ: `/compare` にプレイヤーを2人指定した状態。*

## プロフィールページの見方

各ランナーのプロフィール（`/player/MCIDまたはID`）は、タブで情報が整理されています。

| タブ           | 内容                                              |
| -------------- | ------------------------------------------------- |
| プロフィール   | 自己紹介・ソーシャルリンク・動画                  |
| 活動・記録     | RTA記録、Speedrun.com/MCSR Ranked/PaceMan連携統計 |
| キー配置       | 仮想キーボード表示                                |
| デバイス       | キーボード/マウス設定                             |
| アイテム配置   | ホットバー構成                                    |
| サーチクラフト | クラフト検索一覧                                  |
| ガイド         | そのランナーが公開しているガイド一覧              |

![プロフィールページのタブ一覧](images/usage-11-profile-tabs.png)
*撮影メモ: `/player/:slug` のタブバー全体。*

キー配置タブでは、そのランナーがTrigger/Chat種別のリマップを登録している場合のみ、仮想キーボードの右上に「**Trigger**」「**Chat**」の表示切替ボタンが現れます。ゲーム内でのキー配置を見たいときはTrigger、チャット・サーチクラフト用の配置を見たいときはChatに切り替えます。

![仮想キーボード右上のTrigger/Chat切替ボタン](images/usage-12-profile-remap-toggle.png)
*撮影メモ: `/player/:slug?tab=keybindings` で切替ボタンが見える状態。*

## ホーム画面を使いこなす

トップページ（`/`）には以下の情報が集約されています。

- 最近更新された公開プロフィール
- 最近公開されたガイド
- **ペース**セクション: 現在進行中の「**ライブ**」ペース（15秒ごとに自動更新、右上の更新ボタンで手動更新も可能）と、直近12件の「**過去のペース**」
- 最新のYouTube動画

![ホーム画面のペースセクション。ライブの表と過去のペースのカード、更新ボタン](images/usage-13-home-pace.png)
*撮影メモ: `/` のペースセクション全体。ライブに1件以上の走者がいる状態が理想。*

---

## ランキング・統計を見る

`/rankings` ではRTAのランキングを、`/stats` ではプラットフォーム全体の統計を確認できます。個々のランナーの詳しい統計は各プロフィールの `/player/:slug/stats` からも見られます。

---

## ガイドを読む

ヘッダーの「ガイド」（`/guides`）から、他のランナーが公開している攻略ガイドやサーチクラフトのテンプレートを閲覧できます。タイトル・概要での検索やタグでの絞り込みが可能です。

自分でガイドを書きたい場合は、別記事の「**ガイドのガイド**」を参照してください。

---

## 他アプリからの移行（インポート）

以前MCSRer Hotkeysなどのアプリでキー配置を管理していた場合、`/me/import` からバックアップデータをインポートし、キーリマップやキーバインドをまとめて引き継げます。

---

## 開発者向け機能

フッターの「Developers」（`/developers`）からは、以下の機能にアクセスできます。

- **API**（`/developers/api`）: 公開APIの仕様書
- **チェンジログ**（`/developers/changelog`）: Minefolioの更新履歴
- **エクスポート**（`/developers/export`）: 自分（または検索した任意のユーザー）のキー配置・キーリマップ・カスタムアクション・マウス設定をCSV形式でダウンロード

![エクスポート画面のセクション選択チェックボックスとダウンロードボタン](images/usage-14-developers-export.png)
*撮影メモ: `/developers/export` の入力フォーム全体。*

---

## 困ったときは

不具合報告や要望は `/feedback` から送信できるほか、GitHubリポジトリでのIssue報告も歓迎されています（フッターの「GitHub」リンクから）。
